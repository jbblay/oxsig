# Project Governance

## Roles
- Maintainers: responsible for releases, roadmap, and reviews.
- Contributors: anyone submitting issues, PRs, docs, or tests.

## Decision Making
- Minor changes: handled by maintainers via PR review.
- Major changes: propose an RFC (issue labeled `rfc`) and collect consensus.

## Releases
- Semantic versioning (semver). Changelog in PRs; tags on main.

## Roadmap
- Tracked in `docs/ROADMAP.md`. Grant-funded milestones will be added to `docs/GRANTS.md`.
