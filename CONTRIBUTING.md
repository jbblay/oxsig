# Contributing to OxSig

We welcome contributions from the community! Whether you're fixing a bug, improving documentation, or proposing a new feature, your help is valued.

To get started, please review the following resources:

- **[Development Guide](docs/DEVELOPMENT.md)**: For instructions on how to set up your development environment, run tests, and understand the codebase.
- **[Contribution Guidelines](.github/CONTRIBUTING_GUIDELINES.md)**: For our code of conduct, pull request process, and other policies.

If you have any questions, feel free to open an issue or join our community discussions.
