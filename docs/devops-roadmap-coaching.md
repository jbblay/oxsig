# DevOps roadmap and focused practice

The DevOps career map now covers foundations (Linux, networking, Git, scripting,
cloud), delivery (Docker, CI/CD, infrastructure as code, Kubernetes), operations
(observability, DevSecOps, reliability) and an end-to-end capstone. Docker remains
the only implemented practical skill. Every other node is a curriculum preview;
those nodes never block the Practice Docker shortcut or award achievements.

The Docker workbench puts the objective and coaching selector in the header.
Assignment detail, lab explanation and terminal connection details expand on
request. Connection errors and recovery controls remain visible. Compact terminal
presentation is opt-in for Academy; other terminal consumers retain their layout.

- Beginner: diagnostic commands with short purpose explanations and progressive
  concrete hints.
- Intermediate: diagnostic commands and hypothesis-driven hints.
- Advanced: acceptance criteria and evidence questions; no command list initially.

All levels can explicitly reveal worked commands or request a direct explanation.
Example reveals increment the existing server-side hint counter; help never awards
practical completion. Switching levels hides revealed examples. Commands only copy
to the clipboard and require learner execution. Real mission completion continues
to use the same authenticated server verification, for all coaching levels.

No new backend, migrations, infrastructure permissions or deployment settings.
Unit tests cover hint progression and solution disclosure; Chromium covers all
three levels, assistance recording, clipboard behavior and responsive layouts.
Browser lab/AI fixtures do not constitute live AWS or model-provider testing.
