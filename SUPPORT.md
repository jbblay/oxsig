# Support

We’re excited to help you use and contribute to OxSig.

## Where to ask
- Questions: GitHub Discussions (if enabled) or open an issue with label `question`.
- Bugs: Use the Bug report issue template.
- Features: Use the Feature request issue template.

## Response time
Maintainers are volunteers. Expect first responses within 3–5 business days.

## Security issues
Please do NOT open public issues for vulnerabilities. See SECURITY.md.
